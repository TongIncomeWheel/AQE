# DECISIONS LOG
Every ruling that changes the constitution or rulebook. Newest first. Format: ID · date · decision · what it retires.

> **STANDING PM DIRECTIVE (18 Jul 2026) — anti-spaghetti.** Hold true to the architecture principles (constitution §3 laws 2, 4, 10; D-8). When a need arises, the default is to COMPLETE or CORRECT an existing structure, or build a genuinely new agent/skill — NOT to overlayer prose, flags, or shims on top of what exists. Every change still names what it retires. If a change would add a fourth way to do something that already has three, stop and consolidate instead. This directive governs how every decision below is implemented.
