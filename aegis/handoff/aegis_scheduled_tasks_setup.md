# Aegis — Scheduled tasks (superseded)

The five scheduled tasks are live on the Cowork scheduler. The canonical schedule, trigger IDs,
and prompt template live in **`aegis/SCHEDULERS.md`** — that file is the single source of truth;
this setup guide is retired.

To change a task: edit the prompt via `update_trigger` (or ask Claude in any Aegis session) and
mirror the change in SCHEDULERS.md.
