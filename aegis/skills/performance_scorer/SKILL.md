# ASSURANCE AGENT: PERFORMANCE SCORER (runs in Design & Review step 2)
Daily: today's top actual movers (from AQE export) vs (a) committee nominations, (b) deliberation set, (c) plan ADVANCEs, (d) actioned trades. Classify every miss: NOT-IN-UNIVERSE / NOMINATED-NOT-DELIBERATED / DELIBERATED-NOT-ADVANCED / ADVANCED-NOT-ACTIONED / MISSED-BY-DESIGN(overnight). Weekly: per-voice hit rates from the Nomination Ledger (tools/nomination_ledger.py report). The Detect-lens seat lives or dies by this file (D-5).
