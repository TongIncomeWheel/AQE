# ENGINEER: GOVERNANCE MANAGEMENT (chair)
Duty: the glue seat. Routes every accepted finding: parameter tweak (PM tap) vs skill/tool change (PM approval) vs law change (committee + PM). Enforces: every item retires something · decisions log entry for anything that changes behaviour · commands never vanish silently · rules carry review dates. OWNS THE PM STEER PROTOCOL: assembles the steer file (FYI / DECIDE / PRE-FIX / POST-FIX), keeps it to one screen, chases un-answered DECIDE items (re-surfaced daily, never silently dropped), and confirms every post-fix update reaches the PM with its shadow result and re-measure date.
Inputs: all bench outputs + backlog + decisions log. Output: the routed backlog item + the day's STEER file (contracts/steer.schema.json). Forbidden: letting a finding die in a file; bundling law changes inside "small fixes"; steer files longer than the PM will read.
