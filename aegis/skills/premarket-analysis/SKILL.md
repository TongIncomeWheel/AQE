# /pma — PREMARKET ANALYSIS (v4.4 operational card — supersedes the v0.4 design card)

**Source of truth: `TongIncomeWheel/AQE` branch `main`. Everything this run reads and writes lives there.**
Inputs: `aegis/output/aqe_daily_export.json` + `aegis/output/aqe_crown_macro.json` (fixed names, overwritten daily — the ONLY data sources, never Drive).
Code: `aegis/skills/premarket-analysis/tools/pma_pipeline.py` + `aegis/skills/premarket-analysis/tools/pm_lens.py` + `contracts/voice_menus.json` (fetch fresh from main every run — never a cached copy).
Spec annex: `aegis/skills/premarket-analysis/stages/S6B_post_committee.md` (post-committee contract — consensus rule, ranking key, ledger, card contract, S7Q families). On any conflict, S6B wins.
State: `data/pma/<date>/` (run artifacts) · `data/pma/phase4_ledger.json` (rolling repeat ledger) · `data/pma/verdict_ledger.json` (accountability ledger — every verdict AND every cap-dropped NEAR-MISS, locked live, WRITE-ONCE per date+ticker) · `data/pma/<date>/pm_lens.json` (PM LENS scorecard + committee coverage cross-reference) · `aegis/reports/pma/<date>.md` + `latest.md`.

**Control vs judgment (D-16).** The session running this card is CONTROL: fetch, validate, spawn, collect, run the tool, render, publish. It forms no market opinion. Judgment happens only inside spawned voice agents. Every arithmetic step runs through `pma_pipeline.py` — same inputs, same outputs, no model in the path.

**PACKETS ARE INLINED, NEVER PATHS (finding F1 — re-confirmed the hard way 2026-08-19).** Every spawned voice receives its packet PASTED INTO ITS PROMPT. Never hand a voice a file path and never tell it to read a file. On 2026-08-19 the nominators were spawned with paths to save prompt size: all nine reported reading their packet, all nine recorded ZERO tool calls, and the four that returned output fabricated it wholesale — oneil, thorp and elder-lens each returned 10 nominations of which **0 existed in that day's 136-name universe**, with fluent invented field values (`rs_spy_20d 12.80`, `bq_base_dur 34d`). Re-run with the packet inlined, the same elder-lens seat returned 10 of 10 real tickers with values copied exactly. Inlining is not a preference, it is the control that makes the swarm's output real. **MANDATORY CHECK before the tally: every nominated ticker must exist in `candidate_set.json`. Any voice returning a ticker outside the universe is discarded entirely and re-spawned — its whole return is untrusted, not just the bad row.**

**Unattended rule.** A scheduled firing has no PM watching. Never block on a question: apply the failure ladder, declare every degradation in the report header, and publish. The report footer is always: "DRAFT — PM approval required. Nothing is staged, nothing is armed."

## Procedure

**S0 · PREFLIGHT.** Confirm the GitHub MCP connector answers (one `get_file_contents` on `aegis/output/`). If absent → STOP, no plan, page the PM: the run cannot read its inputs or persist its outputs. Confirm the `aegis-voices` agent types are available (they ship in the aegis-voices plugin). Note UTC/SGT date; the run date is the SGT calendar date.

**S1 · INGEST.** Fetch both input files from `main` (always `ref: refs/heads/main`, never a pinned SHA). Validate: export has `daily_list`, `srm`, `regime`, `macro_weather`; crown file parses. Record staleness (export date vs run date) and every DEGRADED flag — they travel verbatim into the report header. **Check the Crown artifact's own `generated_at` / `how_current.today`, not just its commit date: on 2026-08-19 Crown was committed with the day's data yet was byte-identical to the previous session's file, i.e. a stale macro read under a fresh tape. Declare that explicitly when it happens.** Export missing/invalid → STOP. Crown missing → continue AQE-only, headline says so. Fetch `pma_pipeline.py`, `pm_lens.py`, `voice_menus.json` (it lives at `aegis/skills/premarket-analysis/contracts/voice_menus.json`), `S6B_post_committee.md`, and `data/pma/phase4_ledger.json` to the working dir.

**S2 · TRIM + PACKETS (tool).** `pma_pipeline.py trim` → `candidate_set.json` (full-universe CONSUMED trim, keeps `source`/`on_longlist`/`in_ledger`/`elder*`). Then `pma_pipeline.py packets` → per-voice menu-sliced shuffled TSVs + crown/druckenmiller macro packets. The tool asserts R3 (no `qs_market` in any seat packet) and fails loudly on breach. `qs_market` is PM-only: it appears in the report's macro section as the PM's regime read, never in any seat's input. No-blank-data (2026-08-17, standing PM rule): every menu field null on every row prints as `missing_menu_fields`; every `None` cell writes as the literal token `null`, never blank; names with zero core technical fields (`no_technical_coverage.json`) are held out of nominator TSVs entirely rather than served as walls of nulls (they stay in `candidate_set.json`); names missing only pattern-detection fields print a loud `pattern_field_gap` warning but are NOT held out (they carry real other data). See `S6B_post_committee.md`'s NO-BLANK-DATA section for the full audit and rulings.

**P0 · MACRO VOICES (2 spawns, parallel).** Spawn `aegis-voices:voice-druckenmiller` and the crown voice with their JSON packets INLINED in the prompt (never a path — see finding F1 above). Crown reads its own macro file + the export's sector/theme layer (R6). Druckenmiller reads all macro weather + Crown DATA POINTS, never Crown's prose, never QS (R3); he MUST file `agrees_on`/`differs_on` vs Crown — conflicts are surfaced to the PM, never resolved by the committee. **Druckenmiller never returns a ticker** (design deviation caught on the 2026-08-18 run, where he emitted 10 and they were discarded).

**S4 · SWARM (9 spawns, parallel, blind).** One isolated spawn per nominator: `elder-lens, livermore, minervini, oneil, raschke, seow, thorp, wyckoff, weis`. `kratter` and `ceponas` join once their books are ingested. Each gets: its own agent card (the plugin agent type carries it) + **its own TSV packet inlined in the prompt** + nothing else. No tally, no other voices, no ordering hints. Each returns nominations with ticker, conviction 1–5, reason, `fields_cited`. One re-spawn on invalid return OR on any ticker outside the universe; still bad → seat marked `absent`, quorum check at S6 (≥8). Lynch, Rogers, steenbarger, detect-lens are NOT nominators.

**PHASES 2–4 · TALLY → QUALIFY → RANK → CAP (tool).** **First: universe-membership check on every returned ticker (see F1 above) — discard and re-spawn any seat that invented a name.** Then `pma_pipeline.py tally` and `rank --cap 20`. Qualification: seat_count ≥2 OR solo conviction ≥4. Ranking key (fixed, v4.2): seat_count → conviction_sum → SRM support (sector `entry_gate`: PASS>CAUTION>WATCH>BLOCKED) → thematic support (DEPLOY grade or LEADING/IMPROVING rrg) → sc_momentum. Top-20 = deliberation set. **No gate anywhere in this chain — no sector, fundamental, or bracket term (R1).** Then `pma_pipeline.py ledger` — append ALL qualifiers (survivors + cap-cut) to `phase4_ledger.json`; any ticker at ≥2 appearances in the trailing 5 sessions gets a REPEAT flag → PM manual look.

**S5a · CHALLENGE (2 spawns, after the cap).** Rogers and Steenbarger get the deliberation set + nomination counts → challenge documents (Rogers: crowding, certainty, timing risk; Steenbarger: conviction audit, structural weakness, conviction change risk). Both documents join the Round-2 packet.

**S5b · FUNDAMENTALS + LENS (2 spawns, after the cap).** Lynch activates ONLY on the deliberation set (R5/R7): FMP MCP + web grounding, six-category quick pass per name, every figure with source+date. Detect-lens activates on the deliberation set: technical structure assessment, pattern confirmation, momentum lens. Both memos join the Round-2 packet. If FMP/web is unavailable in this session, Lynch files with an explicit "fundamentals unserved" flag per name — the run continues, degradation declared.

**S6 · ROUND 2 (11 spawns: 9 nominators + lynch + detect-lens as voting seats).** Every seat files SUPPORT/OPPOSE/ABSTAIN on EVERY deliberation-set name plus the obligation register (O1–O8: opposing argument on every OPPOSE, self-counter on high-conviction SUPPORT, falsifier, conviction-change reason, Rogers/Steenbarger challenge answer, direct-challenge replies, Steenbarger conviction_audit). Packets carry: the name's full universe row + all Round-1 reasons (attributed) + Rogers' and Steenbarger's challenges + Lynch's fundamentals memo + Detect-lens's technical lens assessment — all INLINED. Quorum <8 → no ADVANCE possible, watch-table-only run. At 11 voting seats the floor of 8 leaves 3 seats of margin; re-derive on roster change.

**S6.5 · CONSENSUS + SYNTHESIS (tool + compile).** `pma_pipeline.py consensus`: ADVANCE = support>oppose AND support≥2 AND median support conviction ≥3; else support≥2 → HOLD-FOR-CONDITIONS; else PASS. Caps only lower conviction (steenbarger flag→3, support<3→4, non-ADVANCE→3). Compile per-name verdict records: split, strongest opposing case (verbatim, attributed), falsifiers, fundamental line. **Every HOLD-FOR-CONDITIONS gets a mandatory observable condition line** — from a seat's filed promotion condition, else synthesized from the strongest opposing case. No persuasion narration anywhere.

**S6.6 · AUTO-BRACKET (R8, tool-read).** Every deliberation-set name gets levels verbatim from its export `bracket` block: structural stop/TP/R:R if `valid`, else `atr_fallback_stop` labelled FB + nearest overhead levels. Informational only — filters nothing, ranks nothing, vetoes nothing (R1).

**S6.7 · LOCK VERDICTS + REPEAT WATCH (tool, mandatory — PM standing rule, 2026-08-18: "I want it automated, not by hand, which means gaps and forget will occur" otherwise).** `pma_pipeline.py record-verdicts --phase4 <rank output>` — locks every name that reached Phase 4 today into `verdict_ledger.json`: deliberated names get their real verdict (ADVANCE/HOLD-FOR-CONDITIONS/PASS) with ref_price + bracket; cap-dropped names get a NEAR-MISS row with ref_price only. WRITE-ONCE per (date,ticker) — never overwrites a prior lock. Then `pma_pipeline.py repeat-watch` — cross-references `phase4_ledger.json`'s repeat flags against `verdict_ledger.json`'s row history and emits `repeat_watch.json`, containing the exact §4 markdown table (ticker / date appeared / % vs last close / state) to paste into the report. **This step is not optional and its output is not hand-editable** — §4 of the report must be the tool's own `markdown` field, verbatim; S7Q's Q6r family fails the gate if it isn't. Any appearance with no matching verdict-ledger row prints as an explicit gap in the table, never silently invented or omitted.

**S6.8 · PM LENS (tool, mandatory — PM ruling 2026-08-19: "lets have both … we stick to the committee doing their filtering as-is now, but we also flash these names as 'PM lens' — this is to ensure coverage and not prematurely blocking names or over-using tokens to look at too big a list of candidates").** Deterministic, 0 spawns, 0 tokens. `pm_lens.py --export <aqe_daily_export.json> --phase4 <phase4.json> --out data/pma/<date>/pm_lens.json`. Scores EVERY export row against the PM's own six manual checks — C1 on both longlist and elder list · C2 `rs_leadership` LEADER/IN-LINE · C3 `sector_rrg_quadrant` IMPROVING/LEADING (and `thematic_rrg_quadrant` likewise **if the name has a basket** — a null basket is NOT a fail) · C4 `structure_shift` ABOVE_STRUCTURE/BULLISH_BOS · C5 VWAP 5d ABOVE+RISING and 14d ABOVE · C6 **lens count ≥4 of 6 strong AND `coil` strong AND `insti_money` strong** (the coil/insti requirement sits ON TOP of the ≥4 count — it is NOT "all six lenses strong") — then flags every name at ≥`--min-checks` (default 5).
**This layer BLOCKS NOTHING.** It removes no name from the longlist, from any voice's menu, from the tally, or from the deliberation set. The committee's filtering is untouched; this runs beside it.
**Two things are deliberately NOT checks.** `bracket.valid` — entry mechanics, never name quality (PM standing rule; the committee has cleared ADVANCE names with `bracket.valid=False`). And QS — carried as a ranking/display field only, because `qs.odds.edge` is positive on 100% of rows and so cannot discriminate; demoting it from a check changed the flagged list by zero names.
**The coverage cross-reference is the point.** With `--phase4`, every flagged name is tagged DELIBERATED / NOMINATED_CUT_BY_CAP / **UNSEEN**. UNSEEN = passed the PM's checks and drew ZERO nominations, so it appears in no other section of the brief. That is the exact gap that hid TER on 2026-08-18 (5/6 checks, zero nominations, zero mentions; the PM found it by eye a day later). Never suppress an UNSEEN name and never restate it as a verdict — it is a name the committee did not look at, nothing more.

**S7 · RENDER.** Fixed sections, in order: 1 Macro position (Crown + Druckenmiller + the PM-only QS read, conflicts surfaced) · 2 Sector & thematics (SRM table + baskets) · 3 Held book review (from export `held_book`; if stale, one line saying so — the PM refreshes via PTJ) · **4 REPEAT WATCH — paste `repeat_watch.json`'s `markdown` field verbatim, never hand-typed (S6.7)** · **5 QS LIST — every ticker on the `qs` sourcing track this run, rendered in full from `candidate_set.json`'s per-ticker `qs` block (PM request, 2026-08-18: "all tickers on QS list to be shown"), even when the track is empty that day (state so explicitly)** · **6 PM LENS — paste `pm_lens.json`'s `markdown` field verbatim (S6.8): the names passing the PM's own six checks, each tagged with whether the committee actually saw it. Render every run; if nothing is flagged, say so explicitly rather than dropping the section. Any UNSEEN name gets one plain line naming it as a name the committee never looked at — never dressed up as a verdict, never quietly omitted** · 7 Shortlist as TICKER CARDS · 8 Near misses (every cap-cut qualifier, one row each, never grouped) · 9 Action plan addressed to the PM. Card contract (no omissions): header (ticker·verdict·conviction+cap reason·vote S-O-A·sector) · List line (source track + Elder score/pattern/5d + SRM gate + thematic) · scores (conviction/detect/coil/momentum/accumulation/structure) · levels (px/stop[structural|FB]/TP1-2/R:R/ATR) · Committee/Risk/Condition lines · **QS line (MANDATORY, every card, shortlist and near-miss alike — render-only, from `candidate_set.json`'s per-ticker `qs` block, never seen by any voice; print even when `qs.signal == "NONE"`, absence is information too)** · REPEAT flag if ledgered ≥2x/5, pointing to §4 rather than restating the numbers.

**S7Q · QUALITY GATE (tool).** `pma_pipeline.py gate --ledger-phase4 phase4_ledger.json --repeat-watch repeat_watch.json` (plus the Q7L check below against `pm_lens.json`) — mechanical checks: every ADVANCE has support>oppose; every HOLD has a Condition line; all sections present; List/Elder present; zero persuasion phrasing; DRAFT footer; **Q6r — every phase4_ledger repeat flag is covered by `repeat_watch.json` and actually appears in the brief's §4 text (fails a hand-typed §4 even if the numbers happen to be right, because the point is the source, not just today's output).** **Q7L — `pm_lens.json` exists for this run, its `markdown` is what §6 renders, and every UNSEEN ticker it names actually appears in the brief text (a provenance check: it fails a hand-written or omitted §6 even if the names happen to be right).** **Q0U — every ticker anywhere in the report exists in `candidate_set.json` (the F1 fabrication check; a name that is not in the day's universe fails the gate outright).** FAIL → fix at the owning stage, max 2 loops (Q7L fails route back to S6.8 — re-run `pm_lens.py` and re-render §6 from its own markdown; Q0U fails route back to S4 — re-spawn the offending seat with its packet inlined), residuals DECLARED in the footer. Never publish silently defective.

**S7P · PUBLISH.** Push to `main`: `data/pma/<date>/` (candidate_set, tally, phase4, consensus, repeat_watch, pm_lens, run record) + updated `phase4_ledger.json` + updated `verdict_ledger.json` + `aegis/reports/pma/<date>.md` + `aegis/reports/pma/latest.md`. Write the report to the claude.ai project doc (`claude/pma_dryrun_brief_<date>.md` naming continues as `claude/pma_brief_<date>.md`). Print the full report on screen. If the session can send files, send the .md.

**S8 · AUDIT.** Write `data/pma/<date>/run_audit.json`: seats spawned/responded, **tool_calls recorded per seat (a nominator returning content with zero tool calls and zero inlined packet is the F1 signature)**, universe-membership check result, stage receipts, gate result, degradations, spawn count, wall time. This is the learning loop's input.

## Failure ladder (unattended-safe)
Export missing/invalid → STOP, no plan · Crown missing → AQE-only, declared · **Crown present but not regenerated (byte-identical to the prior session) → run on it, but declare the staleness in the header and say what it does not license** · seat absent after re-spawn → quorum math, declared · **any seat returning a ticker outside the universe → discard that seat's ENTIRE return, re-spawn once with the packet inlined, then mark absent (F1)** · FMP absent → Lynch files unserved flags · **PM LENS tool fails → declare it in the header and render §6 as an explicit "PM LENS did not run this session" line; never hand-write the table, and never drop the section silently** · GitHub write fails at S7P → report still prints on screen + project doc, push retried once, failure declared · anything DEGRADED → verbatim in the header.
